FlowSight 6.0.7 vincula la concentración total con el reloj principal en Windows.

- Iniciar concentración total activa el reloj después de confirmar la protección del navegador.
- Pausar y reanudar desde el reloj controlan también la concentración: la pausa conserva el tiempo restante y libera los bloqueos y el silencio de Windows; la reanudación vuelve a confirmar las protecciones antes de contar.
- Finalizar desde Ajustes o detener desde el reloj termina ambos y conserva el tiempo registrado del día. La caducidad y la salida de emergencia del navegador también detienen el reloj vinculado.
- La sesión pausada sobrevive al reinicio. El reloj muestra el tiempo registrado del día y debajo el tiempo de concentración restante.
- Pulsar Iniciar con la tarea vacía lleva al campo y muestra el error allí. Durante la activación se muestra el progreso y, si falla, el error permanece visible para reintentar.

Mantiene el bloqueo de páginas y rutas, las excepciones, el silencio opcional de avisos de Windows y los recordatorios locales guardados. Las respuestas automáticas de mensajería siguen previstas para una futura integración.

Incluye Browser Controls 1.1.2. Esta release corresponde al agente de Windows.

Validado con pruebas nativas, del renderer, la extensión MV3 y el flujo completo del reloj en tamaños pequeño, compacto y amplio, además de las comprobaciones de compilación de Windows.
