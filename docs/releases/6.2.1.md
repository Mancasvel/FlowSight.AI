# FlowSight 6.2.1 — Encuentra el trabajo que quieres contar

- **Build in public** busca el tema que pides en todo el periodo elegido. Trabajos como un proyecto con ESP32 ya no quedan fuera por tener menos tiempo registrado o por no aparecer entre las actividades más recientes.
- Nueva opción **«Incluir mis prompts locales de Codex»**: añade tus mensajes del periodo para encontrar ideas sobre el trabajo que has pedido a tu asistente. Se leen en tu equipo y cada idea conserva su fuente para revisarla.
- Las propuestas se construyen a partir del material encontrado, sin una lista fija de enfoques. **«Más ideas»** evita volver a utilizar las mismas fuentes y te avisa cuando se agota el material.
- Si no hay coincidencias con el tema o solo hay unas pocas ideas, FlowSight lo indica y muestra las propuestas disponibles. Tus correcciones y las tandas anteriores se conservan.

Para buscar trabajo que hayas tratado con Codex, abre **Online → Build in public → Ideas**, elige el periodo, activa **«Incluir mis prompts locales de Codex»** y escribe el tema en **«¿Qué te gustaría contar?»**. Revisa qué se completó antes de guardar una idea: un prompt documenta lo solicitado y no confirma por sí solo el resultado. Después puedes seleccionar la idea y preparar su prompt de contenido.
