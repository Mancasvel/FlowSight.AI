# FlowSight 6.5.2 — Individual y gestión de equipos

- Individual es el modo predeterminado cuando no tienes un equipo activo. Una elección antigua de Equipo ya no abre el inicio de sesión automáticamente.
- Las licencias Individual anteriores recuperan sus herramientas personales aunque todavía no tengan guardado el nuevo perfil.
- Los empleados vinculados a un equipo mantienen la pantalla sencilla de Parar y Continuar, también durante una caída temporal de conexión.
- Los project managers gestionan el equipo desde el dashboard web. La app ofrece Individual y el registro para empleados; el rol de gestión permanece en la web.
