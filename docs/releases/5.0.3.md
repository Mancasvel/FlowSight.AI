# FlowSight Agent 5.0.3 for Windows

The first stable FlowSight 5 release replaces the Qwen3.5 preview checkpoint with the official **Qwen3-VL-2B-Instruct** Q4_K_M language model and Q8_0 visual projector. One local model handles screen context and report assistance. The model is not fine-tuned by FlowSight.

## Changes

- The app downloads approximately 1.55 GB of model data on first use, verifies both SHA-256 hashes, and runs inference locally afterward.
- Optional focus reminders can now ask the local model for a single `send_focus_notification` proposal. FlowSight sends only aggregate counts to the model, verifies the observed signal, consent and cooldown, and displays fixed notification text. The internal tool is unavailable to external MCP clients.
- Status reports favor findings backed by recorded activity and avoid presenting passive observations as completed work.

## Installation and update

Windows 10/11 x64: use the NSIS installer for automatic updates, or the MSI for manual installation. The updater manifest is included in this release. The first model download requires internet access; inference works offline after verification.

The local model has been smoke tested for multimodal responses and tool calls. The exploratory screen benchmark is not a production accuracy guarantee.
