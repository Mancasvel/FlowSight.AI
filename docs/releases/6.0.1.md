FlowSight 6.0.1 fixes repeated update and local tracking acknowledgement prompts on Windows.

- Opening the installed app refreshes an existing launch-at-login entry to its current executable, including entries left pointing to an older development copy. Paths containing spaces are quoted correctly. Startup stays disabled if you disabled it in Windows Task Manager.
- Local Cargo builds cannot replace the installed application's launch-at-login entry.
- The saved acknowledgement from the August production notice or the September local build remains valid across restarts. Reading it no longer waits for the account service, and a temporary read failure does not create a false first-time consent prompt.
- Your original acknowledgement date, account, local history and separate optional sharing choices are retained. Withdrawn choices and unknown notice versions still require acknowledgement.

Windows: install the `-setup.exe` package or use the MSI. Existing installations can update from the app.
