# Build in public — product and implementation record

## Product decision

Add a personal studio inside **FlowSight.AI → Online → Build in public**, beside the existing private leagues. This is a native Tauri app feature, not a page in the separate web dashboard. Its job is to turn a selected day's or week's real work into a small number of useful stories, then adapt each story for LinkedIn, X and Instagram. The advantage is the work evidence already collected on-device, coupled with explicit user confirmation of outcomes and learning.

The initial audience is solo builders and founders. A successful pilot produces one accurate, publishable story in under five minutes of review. Track suggestion acceptance, edits needed, repeat weekly use, and time from evidence to approved draft. Do not optimize for automatically generated volume. Monetization and audience-wide rollout follow evidence from the pilot.

## Intended journey

1. Use the existing FlowSight app session; the collector and model already run locally.
2. Choose daily or weekly coverage. The collector filters and minimizes observations locally.
3. Review candidate evidence, confirm the outcome, and remove private material.
4. Generate channel-specific drafts locally or use a scoped assistant connection.
5. Edit and approve the exact revision. Instagram includes an editable visual.
6. Connect social channels and hand off approved content. Save provider receipts; ambiguous submissions must not be blindly retried.

## Implementation and verification

Updated as the pilot is built. Test fixtures must be labeled synthetic and must never be confused with the user's real work. No public post is authorized by the implementation request alone.
